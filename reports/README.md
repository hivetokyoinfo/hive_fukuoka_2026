# Annual Reports

年度ごとの開催レポートを `reports/YYYY/index.html` に保存します。

新しい年度を追加するときは、直近年度のフォルダを複製してから、次をすべて更新します。

- title、description、canonical、OGP、構造化データ
- 開催日、概要、登壇者、プログラム、協力先
- 写真パスと代替テキスト
- トップページからの最新年度リンク
- `sitemap.xml` の年度ページURLと更新日

過年度ページは上書きせず、その年の記録として残します。公開前の確認は `docs/ANNUAL_RELEASE_CHECKLIST.md` を使用してください。
