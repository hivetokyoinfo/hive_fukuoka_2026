# 2026年版の素材配置

素材は掲載許諾を確認したうえで、ローカルにのみ配置してください。このディレクトリの画像はGit管理しません。

## 写真

次の番号で始まる写真を `photos/selected/` に1枚ずつ配置します。番号より後ろのファイル名は任意です。

```text
003 007 014 019 022 037 043 048
050 061 091 094 116 139 143 220
```

配置例:

```text
assets/photos/selected/003_cover.jpg
assets/photos/selected/007_group.jpg
```

## 写真確認

- 元画像の縦横比を変形しない
- 顔や目が不自然に切れないクロップにする
- Day 1とDay 2の時系列を確認する
- 同じ場面の写真を重複して使いすぎない
- 掲載NGの人物が写っていないことを確認する
- 最終ページには参加者が正面を向いた集合写真を使う
