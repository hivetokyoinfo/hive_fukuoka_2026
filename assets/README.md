# Assets

公開サイトで使用する、軽量化済みの素材だけを置きます。

```text
assets/
├── css/          共通スタイル
├── js/           共通スクリプト
├── images/
│   ├── shared/   年度をまたいで使用する素材
│   └── YYYY/     各年度の掲載許諾済みWeb画像
└── meta/         OGPなど検索・SNS表示用画像
```

## 画像のルール

- 元写真は置かず、WebPまたは用途に適したJPEGへ変換する
- CSSやHTMLで縦横比を変形しない
- ファイル名は内容が分かる英小文字とハイフンで付ける
- 同じ画像を年度をまたいで複製しない
- 掲載許諾と写り込みを確認してから追加する
- 一時プレビュー、スクリーンショット、編集途中の画像はコミットしない

年度ページから使う写真は `images/YYYY/`、Hive Japanや他地域など共通で使う素材は `images/shared/` に置きます。
